# Bagus Merta

Minimal personal portfolio and writing site built with Astro.

## Features

- Founder-style profile and about page
- Project case studies
- Markdown blog with RSS
- Curated bookmarks
- Responsive dark interface
- Open Graph and Twitter metadata
- Fullscreen image viewer for articles and projects

## Stack

- Astro
- React islands
- Tailwind CSS
- Astro Content Collections
- pnpm

## Commands

```sh
pnpm install
pnpm dev
pnpm build
pnpm preview
```

Content lives in `src/content`, routes in `src/pages`, and static media in `public`.
